# Airport Management System

An academic project focused on the design and documentation of an Airport Management System (AMS). The goal is a comprehensive system design document that models the structure and behavior of a real-world airport platform using software engineering techniques.

## Project Overview
The Airport Management System is an integrated software platform intended to support and coordinate primary airport operations. Airports involve complex interactions between airlines, passengers, ground staff, security authorities, and administrative departments. Managing these operations manually or through isolated systems leads to inefficiencies, delays, and data inconsistencies.

The AMS centralizes airport operations into a single digital environment where data can be managed, accessed, and updated in real time. It supports staff in handling flights, passengers, aircraft, scheduling, security monitoring, and operational reporting.

## Aim of the System
The primary aim is to improve the efficiency, coordination, and reliability of airport operations by integrating multiple processes into a centralized information system.

Key outcomes include:
- Simplified and automated operational workflows.
- Accurate, shared information across departments.
- Real-time updates for flight status, check-ins, gate assignments, and resource management.
- Better decision-making through centralized reporting and data visibility.

## User Levels
The system supports multiple user roles with distinct permissions and responsibilities.

### System Administrator
Manages overall configuration and maintenance. Responsibilities include creating user accounts, assigning roles, maintaining security, and monitoring system performance.

### Airport Operations Staff
Manage daily airport activities such as updating schedules, assigning gates, coordinating arrivals and departures, and monitoring operational status.

### Airline Staff
Manage airline-specific operations including passenger lists, check-in processes, flight information updates, and boarding coordination.

### Security Personnel
Monitor screening, security alerts, and restricted areas. Record incidents and track security-related events with appropriate access controls.

### Passengers (Limited Access)
Access flight information and check-in confirmations via displays, kiosks, or mobile applications.

## General Requirements
The AMS must fulfill key functional and operational requirements:

### Flight Management
- Create, update, and manage flight schedules.
- Record flight numbers, airlines, destinations, arrival/departure times, and status.
- Support real-time updates for delays, cancellations, and gate changes.

### Passenger Management
- Store passenger details linked to flights.
- Manage check-in processes and boarding status.
- Protect passenger data while allowing authorized access.

### Gate and Resource Allocation
- Assign gates, terminals, and boarding areas.
- Adjust assignments as needed to optimize flow.

### Security Monitoring
- Provide access to security alerts and monitoring information.
- Record incidents and track security events.
- Enforce strict access controls for sensitive data.

### Reporting and Monitoring
- Generate reports on flight statistics, passenger volumes, delays, and system usage.
- Support operational and strategic decision-making.

### Financing
- Track airport-related revenues (fees, services, rentals) and operational costs.
- Support budgeting and financial reporting for management oversight.
- Maintain auditable records for transactions and approvals.

### Human Resources
- Manage staff profiles, roles, certifications, and shift assignments.
- Support scheduling for operational coverage and compliance.
- Maintain access to HR data with strict privacy controls.

### Baggage Management
- Track baggage check-in, transfers, and delivery status.
- Integrate baggage routing with flight and gate changes.
- Support incident handling for lost, delayed, or damaged baggage.

### User Authentication and Access Control
- Implement secure authentication.
- Enforce role-based permissions to protect system integrity.
